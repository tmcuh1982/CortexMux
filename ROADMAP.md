# Roadmap

## 0.2

- Explicit capability registry persisted in TOML.
- Richer ComfyUI progress events and reusable workflow catalogs.
- More deterministic data operations and report customization.
- Additional provider plug-in examples without changing router internals.

Possible later work includes a separately maintained web UI, cloud-provider
adapters, vector storage integrations, and deployment recipes. These are not
part of 0.1.0.
